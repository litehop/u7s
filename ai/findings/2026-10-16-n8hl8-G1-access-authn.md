Attacker positions: UNAUTH = unauthenticated network, AUTH = any authenticated user, NS = namespaced low-priv user, NODE = kubelet/node identity, SCOPED = holder of a narrow cluster-level verb.

## Fix sketches
- G1-1: delete `RbacBinding.namespace`; always `extract_namespace(key)`; reject unknown top-level fields on RBAC kinds.
- G1-2: in `put_approval`/`patch_approval` authorize `approve` on `certificates.k8s.io/signers/<spec.signerName>` (or `<domain>/*`); in CSR status writes require `sign`, and reject Approved/Denied conditions via `/status` and certificate-writes without `sign`.
- G1-3: make `field_selector_selects_node` and `auth.rs field_selector_name` use `FieldSelector::parse` (split_terms/unescape) and require the parsed selector to contain an exact-match term AND reject selectors that parse to a single non-matching term.
- G1-4: delete `delete_namespace_scoped_crds` from the prod path (gate behind a test-only flag or exact token match + authz on CRD delete).
- G1-5: parse the store/API key structurally (segments), not `contains`.
- G1-6/7: implement upstream escalation semantics (`escalate` verb on authoring, `bind` on binding, check ALWAYS, include RoleBindings); remove `bind`/`escalate` from seeded `admin`.
- G1-8: restore `metadata.name`/`namespace` (and reject changes) after every patch type, incl. CR path.
- G1-9: set explicit validity (CA 10y, leaf <=1y) + rotation; add CRL or short-lived certs.
- G1-10: expiring one-use bootstrap tokens.
- G1-11: NodeRestriction for csinodes/leases/nodes create/resourceslices.
- G1-14: parse `watch` with the same decoder as the handler (decode query first); HEAD on collection -> `list`.

## Checked and OK
- Central authz: every non-exempt route passes `AuthLayer` (outermost of router; aggregator middleware, fallback and `inject_dry_run_header` sit inside it); `parse_path` vs axum routing: percent-encoded/`//` path variants fail closed (raw segment can never equal a granted name).
- `/metrics` and `/openid/*`, `/version`: RBAC-gated via non-resource URL rules; `/healthz|/livez|/readyz` exempt exactly (no verbose subpaths).
- Bearer parsing: scheme case-insensitive, empty token rejected at load (6hg4r fixed), constant-time static-token compare, non-Bearer falls through to cert (t9pt2 fixed).
- SA JWT: RS256 pinned, issuer fixed, exp (no leeway), audience re-checked on cache hits, bound SA/Pod liveness with UID; whole-token sig cache (4ggk0 fixed).
- Impersonation: user/group/uid/extra each authorized, SA-shaped users use namespaced `serviceaccounts` (1a9pr, d01ew, hfjdl fixed); orphaned Impersonate-* -> 400.
- Client cert: rustls WebPki verify against cluster CA only; front-proxy CA is separate and not in client trust store; no request-header authn (u7s only asserts X-Remote-* to backends, never reads them; inbound X-Remote-* not forwarded).
- Anonymous: only `system:unauthenticated` -> public-info-viewer; basic-user/discovery bound to `system:authenticated`.
- RBAC engine: `resource/*` semantics fixed (9c8iq), resourceNames need a name (create never matches), SA subject match, namespaced bindings only for namespaced requests, synchronous index updates, rV floor.
- Escalation checks present on create, replace, patch, SSA for CRB/ClusterRole/RB/Role (gaps in G1-6/7).
- Continue tokens HMAC-signed, store query bounded by prefix; DRY_RUN header stripped from clients; SAR/SSAR/TokenReview require authz; SelfSubjectReview uses authenticated identity.
- Proxy hardening verified present: portforward `ports` validation (z54ge), podIP validated against node (k6m4a), endpoint address range check for services/proxy.
- NodeRestriction pieces present: node self-write restriction on Node + /status, mirror-pod create, PCR create.
